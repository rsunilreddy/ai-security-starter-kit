# Security Policy

## Reporting a vulnerability
Please do **not** open a public issue containing secrets, personal data, exploit details, or confidential information. For a real public repository, configure GitHub private vulnerability reporting or publish a dedicated security contact.

## Scope
This repository is an educational reference implementation. It is not a production security control and does not guarantee detection of sensitive information.

## Safe handling
Never use real credentials or confidential/customer data in demos, tests, screenshots, issues, or pull requests.
